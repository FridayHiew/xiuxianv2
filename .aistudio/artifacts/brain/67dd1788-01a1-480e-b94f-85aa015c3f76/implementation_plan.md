# 《宗门先祖青史策》传承编年系统

## 1. 轮回道陨青史铭刻 (`js/systems/sect-chronicles.js`)
- 当角色因战斗失利身陨、寿元耗尽坐化或达到剧终大结局时，在清除角色档前自动将其道途因果写入永久保存的宗门青史存储（`xiuxian_sect_chronicles`）。
- 记录核心要素：
  - **玩家道号**（如：韩立、陆长生）
  - **仙历年份与在世天数**（仙历第 X 年、在世 X 日、享年 X 岁）
  - **生前修为境界**（如：筑基 · 前期3重、金丹 · 后期7重）
  - **道陨因果**（如：外出历练喋血于黑风狼王之手、寿元大限枯竭坐化于洞府之中等）
  - **门派位阶与生前伴生灵兽**。

## 2. 重生拜入宗门授书 (`js/systems/character.js`)
- 玩家转世重生开辟新道途后，在拜入宗门（`joinSect`）并参加入门仪式时，由宗门执事正式授予本门代代相传的至宝——**《宗门先祖青史策》**（物品 ID：`sect_chronicle_scroll`）。
- 仪式剧情与日志同步说明此古卷传承渊源：「后辈弟子当以史为鉴，莫蹈前人覆辙」。

## 3. 随身行囊【道具 > 特别】置顶查阅 (Always on Top)
- 背包（`BAG_TABS`）首栏新增**「✨ 特别」**分类标签。
- 《宗门先祖青史策》具有 `pinned: true` 属性，在排序时享有**绝对置顶特权（always on top）**，并饰以华贵流光金边与「📜 宗门传世 · 置顶」徽章。
- 点击直接一键展卷「研读」。

## 4. 古卷青史展卷交互界面 (`js/ui/sect-chronicles.js`)
- 采用宣纸长卷装裱风格，卷首题跋标明当前掌卷弟子道号、当前境界与已收录先贤代数。
- 逆时间轴依序列出历代先贤卡片（第一代、第二代……最新一世高亮「前世因果」红签）。
- 若尚未有先贤身陨，则呈现「青史初卷 · 待载英杰」之宗门寄语。
