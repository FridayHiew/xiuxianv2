# 水墨修仙 UI/UX 全面重构计划（参考《一念逍遥》交互范式）

将《修仙人生》从传统的“多级标签页 + 冗长文字卡片列表”升级为沉浸式**水墨山河画卷 + 底部常驻六大圆章导航 + 圆形汉字印章节点 + 极简行囊列表**的竖屏修仙交互体验。

### User Review & Critical Decisions

> [!IMPORTANT]
> 以下为您在问答阶段确认的核心设计决策，将作为本次 UI/UX 改造的最高准则：

- **Confirmed Decision 1（底部常驻六大圆章导航）**：采用固定在屏幕底部的六大水墨书法圆章导航——**【人物】【历练】【日常】【宗门】【洞府】【行囊】**，任何主页面下始终保持常驻可见，一键切换。
- **Confirmed Decision 2（水墨场景画卷 + 圆形印章节点交互）**：【洞府】【宗门】【历练/秘境】主视图改为全屏水墨山河意境背景，功能入口以“黑底金字圆形印章节点”（如：`丹` 丹房、`药` 药园、`兽` 灵兽、`宗` 宗门大殿、`藏` 藏经阁等）错落排布于山河建筑之上，点击印章弹出对应功能抽屉或面板。
- **Confirmed Decision 3（行囊与商店物品极简展示）**：严格遵循参考图，顶部设分类筛选（全部 / 装备 / 丹药 / 材料 / 特殊），列表每一行**仅显示【图标方框 + 物品名称（按品阶着色） + 数量 `xN`】**，去除列表中冗余的属性描述与按钮，点击该行才弹出详情与使用/装备操作。
- **Confirmed Decision 4（顶部精简境界货币条 + 底部半透明日志框）**：顶部固定一行高对比度墨色状态栏（境界修为进度、灵石、铜钱、道历年份与快捷仙音/设置按钮）；底部导航栏正上方悬浮半透明水墨传音/机缘日志框（默认显示最新 3~4 条，点击可展开完整日志或收起）。

### 1. Overview & Core Concept

- **What It Does**：重构主界面骨架、导航体系、人物装配页、行囊列表页以及洞府/宗门/历练三大场景地图，使玩家在一屏之内即可体验水墨修真世界的空间纵深感与干净利落的触控交互。
- **Target Audience / Persona**：喜爱《一念逍遥》等国风水墨修仙放置/RPG 体验的玩家，追求清爽视觉层级、单手拇指触控友好、无冗余文字堆砌的沉浸感。
- **Key Value**：
  1. **消除信息过载**：物品列表不再堆砌大段说明文字，仅保留名字与数量，按需点击查看详情。
  2. **零迷路导航**：底部六大圆章常驻，【人物】与【行囊】从弹窗提升为一级主页面，主线剧情与仙友同道作为右上角水墨圆章快捷入口随时呼出。
  3. **空间意境升级**：将原本平铺的二级子标签（Subtabs）转化为山河楼阁上的圆形印章节点与立柱幡旗。

### 2. User Experience & Visual Design

#### A. 核心页面与交互流（Key User Flows）

1. **一屏式全局骨架（Global Viewport Frame）**
   - **顶部墨玉状态栏（Fixed Top HUD）**：单行紧凑排布「当前境界与修为百分比」「气血/灵力简明态」「灵石」「铜钱」及「道历年份」，右侧配仙乐与系统维护小图标。
   - **中央主画卷视口（Main Stage Canvas）**：占据屏幕核心区域，根据底部选中的圆章切换六大主视图，内部支持水墨背景节点交互或平滑滚动列表。
   - **底部传音/日志浮层（Collapsible Log Overlay）**：位于底部导航栏正上方，半透明水墨渐变底，实时滚动展示最近 3 条修仙日志/奇遇传音，点击可弹出完整历史记录。
   - **底部六大水墨圆章导航栏（Persistent Bottom Nav）**：固定于视口最底端，包含：`人物`、`历练`、`日常`、`宗门`、`洞府`、`行囊` 六枚古风宣纸水墨圆章，选中态呈现金圈微光与朱砂印记。

2. **六大核心主视图设计**
   - **【人物】视图（参考图 4）**：
     - 中央展示修真者水墨立绘背景与道号、宗门身份、总战力太极徽章。
     - 左侧纵向排列圆形水墨按钮：**「功法」**（心法参悟与切换）、**「法术/神通」**（已学法术与武学招式）、**「灵根/逆天」**（灵根与逆天造化宝物）。
     - 右侧双列排布装备与法宝槽位方格（仅展示图标、强化/品阶角标与简短槽位名，点击槽位弹出装备详情或更换列表），下方配「一键装备」与「属性详情」按钮。
     - 底部直观展示红色的**气血条**、蓝色的**真元（灵力）条**及四维核心属性（攻击、防御、速度、气运）。
   - **【行囊】视图（参考图 5）**：
     - 顶部横向五分类按钮：**「全部」「装备」「丹药」「材料」「特殊」**。
     - 列表区采用浅宣纸质感横条卡片：左侧为带品阶底框的物品图标，中间仅显示**物品名称**（按凡品绿、灵品蓝、玄品紫、仙品金、神品红着色），最右侧显示**数量 `xN`**。
     - **交互准则**：列表内不显示任何长文本描述或操作按钮；点击任意物品行，立即呼出「道具灵鉴」详情弹窗（内含完整属性说明及“服用 / 装备 / 参悟 / 出售”按钮）。
     - 商店、坊市、丹方阁与装备铺中的物品列表同步遵循“仅显示名字与价格/数量，点击弹出详情与购买确认”的极简规范。
   - **【洞府】视图（参考图 1）**：
     - 水墨灵山云海背景，顶部显示“道历XXXX年 · 洞府”，右上角设**「仙友」**（原仙友同道社交）、**「主线」**（主线道途章节）水墨圆章按钮。
     - 画面中央为打坐修炼小人（显示当前主修心法与「修炼中 / 打坐突破」入口）。
     - 山峰楼阁间错落分布圆形黑底金字印章节点：**`聚` 聚灵阵/洞府设施**、**`丹` 丹房**、**`药` 药园**、**`器` 器室（炼器房）**、**`兽` 灵兽**、**`命` 逆天宝物**。点击任意印章，以水墨卷轴弹窗/抽屉形式打开对应功能面板。
   - **【宗门】视图（参考图 3）**：
     - 左上角展示宗门徽章、宗门名称、当前身份与宗门贡献；右上角排列圆形水墨按钮：**「战榜」**（门外/门内战榜）、**「晋升」**（晋升考核与规则）。
     - 水墨仙门群峰背景上排布圆形印章节点：**`殿` 宗门大殿（简介/拜师）**、**`务` 宗门事务**、**`传` 传功殿**、**`藏` 藏经阁**、**`器` 装备铺**、**`丹` 丹方阁（门内以上显示）**、**`市` 杂役铺/坊市**。点击印章进入对应殿堂面板。
   - **【历练】视图（参考图 6）**：
     - 水墨山河大地图背景，各历练区域（黑风林、断魂崖、万妖谷等）以**竖排黑金碑林幡旗**（带序号 1、2、3… 与危险度角标）由近及远错落分布在山川河流之上；右上角或特定节点展示**「秘境探索」**入口。
     - 点击任意竖排地名幡旗，弹出该历练地的层数、建议战力对比与「进入历练」确认框。
   - **【日常】视图（参考图 2 城镇/日常事务风格）**：
     - 整合每日时段行动、杂务差事、野外探索、闲暇雅兴（琴棋书画钓）、闭关修炼等日常操作，以清晰的水墨建筑/人物节点与快捷行动面板呈现。

#### B. 视觉规范与配色体系（Visual Identity & Theme）

- **Aesthetic Direction**：国风水墨丹青（Ink-Wash & Parchment Gold）。
- **Color Palette & Mood**：
  - *水墨画卷底色（Canvas）*：深邃苍山墨色 `#14181c` 与烟云米宣色 `#e8e2d5` 结合，营造水墨留白与古卷质感。
  - *宣纸列表卡片（Parchment Row Surface）*：行囊与弹窗列表采用温润宣纸白/浅米灰 `#dfd9ce`（配 `#9e9689` 细线内边框），文字清晰易读。
  - *印章与强调色（Seal & Accents）*：印章节点采用乌金墨底 `#231914` 配泥金书法字 `#f3d999`；提示角标采用朱砂红 `#c93b2b`。
  - *品阶色彩（Rarity Tiers）*：凡品 `#3b7a47`（翠绿）、灵品 `#2d6ca2`（靛蓝）、玄品 `#7b429e`（紫气）、真传/金丹 `#c87d20`（琥珀金）、逆天/仙品 `#c93b2b`（朱红）。
- **Typography & Hierarchy**：
  - 印章、底部导航圆章、竖排地图碑名采用楷体/行书古风衬线字体（`"STKaiti", "KaiTi", "Noto Serif SC", serif`），字重饱满。
  - 数值（战力、气血、数量 `x3`、货币）统一启用等宽数字对齐（`tabular-nums`）。

### 3. Key Product Decisions & Trade-Offs

- **Decision 1：将【人物】与【行囊】提升为底部常驻一级导航，【主线】与【仙友】移至场景右上角圆章**
  - *Chosen Approach*：底部固定六大高频模块（人物、历练、日常、宗门、洞府、行囊），并在洞府/日常右上角固定「主线」「仙友」圆章入口（有新剧情时显示朱砂红点提示）。
  - *Why*：完全契合参考图的六圆章底部导航结构，玩家查看装备、服用丹药无需再额外点开右上角小图标弹窗，同时保证主线与NPC交互随手可达，零功能丢失。
- **Decision 2：洞府与宗门采用“山河印章节点 + 卷轴抽屉面板”双层结构**
  - *Chosen Approach*：进入洞府或宗门时默认展示水墨山河全景与各建筑圆形印章（如 `丹` 丹房、`传` 传功殿）；点击印章后在当前画面弹出水墨卷轴面板展示具体功能（炼丹炉、心法兑换等），面板顶部带「返回全景」按钮。
  - *Why*：既还原了参考图中极具仙侠意境的建筑节点分布，又完整保留了炼丹、炼器、灵兽喂养、心法兑换等所有深度交互逻辑。
- **Decision 3：行囊与商店全面推行“仅图标+名字+数量”极简行**
  - *Chosen Approach*：移除列表行内的属性标签群、长段文字说明与行内操作按钮，整行作为点击热区（`min-height: 54px`），点击后调用统一的 `showItemDetail(itemId)` 灵鉴弹窗完成查看与使用。
  - *Why*：解决此前背包物品多时满屏文字杂乱的问题，视觉干净度与触控体验大幅提升。

#### B. 状态与交互映射（Interactive Component & State Mapping）

- **全局导航状态（`currentTab`）**：
  - 支持六大主视图键值：`"profile"`（人物）、`"adventureMap"`（历练与秘境地图）、`"day"`（日常与城乡事务）、`"sect"`（宗门画卷）、`"cave"`（洞府画卷）、`"bag"`（行囊）。
  - 右上角快捷圆章支持一键打开主线剧情（`"story"`）与仙友同道（`"social"`）视图或卷轴弹窗。
- **场景节点与二级面板状态（`activeSceneModal` / `currentSectTab` / `currentCaveTab`）**：
  - 在【宗门】或【洞府】水墨全景中点击圆形印章（例如 `openSectNode('传功殿')` 或 `openCaveNode('alchemy')`），弹出带水墨卷轴边框的二级面板展示具体内容，点击关闭或背景即可回到水墨山河主景。
- **行囊分类与极简列表交互（`currentBagCategory`）**：
  - 分类映射：`all`（全部）、`equip`（装备/法宝/逆天）、`pill`（丹药/兽粮/突破丹）、`mat`（炼丹/炼器材料）、`special`（功法残卷/法术秘籍/技能书/杂物）。
  - 点击任意行触发 `showItemDetail(itemId)`，在弹窗中提供「服用」「装配」「参悟」「出售」等完整上下文操作，操作完成后自动刷新行囊列表与顶部状态栏。
